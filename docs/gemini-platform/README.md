## Executive summary

Целевая архитектура — гибридная управляемая multi-agent система: агентная
оркестрация и governance на Agent Platform, агентная логика в ADK, доступ к
партнёрскому MCP серверу через Agent Gateway / Agent Registry / Agent Identity,
приватный retrieval через RAG Engine / Agent Search, события и фоновые операции
через Pub/Sub + Eventarc + Cloud Run.

Шесть решений, на которых держится весь дизайн:

1. **Не один универсальный агент, а несколько специализированных** вокруг общего
   состояния проекта: сценарный анализ, разбор сцен, планирование съёмок, работа
   с ассетами, коллаборация, fan-facing и отдельный агент-контролёр.
2. **Два контура данных.** Внутренний — для съёмочной группы, fan-facing — только
   опубликованные материалы. Разделение проходит по данным и retrieval, а не по
   инструкции в промпте.
3. **Факты вычисляются, мнения генерируются.** Номера сцен, состав, конфликты и
   ранжирование вариантов — детерминированный код. Модель объясняет и
   резюмирует поверх этих фактов.
4. **HITL — правило, а не опция.** Публикация, утверждение расписания,
   fan-facing релиз, юридически чувствительные и бюджетные действия не
   выполняются автоматически.
5. **Партнёрский MCP — через governed layer** с idempotency-ключами, машинно-
   читаемой моделью ошибок и деградацией на локальную эвристику при отказе.
6. **Всё логируется как audit trail**, включая отказы доступа, стоимость прогона
   и решения людей.

## Статус источников

Продуктовые референсы (PinoCut, Bassito) взяты из публичных описаний и
используются как архитектурные паттерны, а не как нормативная спецификация.
Ценовые и функциональные параметры платформы приведены как плановые ориентиры из
исходного ТЗ — их нужно перепроверить у вендора до фиксации бюджета и до
production-развёртывания.

Спецификация партнёрского MCP сервера на момент написания не предоставлена,
поэтому в [mcp-contract.md](mcp-contract.md) зафиксирован contract assumption,
на который написана референсная реализация; при получении реальных endpoints
меняется адаптер, а не агентный слой.
