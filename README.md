# RFV Media Assets

Branch dedicated to character reference sheets and other media used by
RomeoFlexVision pipelines (PinoCut, Bassito, Higgsfield generations).

## Structure
- `character_sheets/fiery_paw/` — Огненная Лапа character canon
  - `atlasito_sheet.png` — Атласито (Leader of Dog Guardians, golden retriever samurai)
  - `boar_antagonist_sheet.png` — Wild boar antagonist (grey, axe-wielder)
  - `atlasito_boar_combined.png` — vertical composite for single-reference Soul V2 calls
